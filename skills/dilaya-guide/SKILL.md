# Dilaya help & tutorials

Plain-language help you RELAY to the person — most are not technical: no jargon ("schema", "table", "Lambda"). Every text exists in French and in English: use the language of the conversation (`.fr.md` / `.en.md`).

## A new or unsure user
Relay the welcome: [fr](references/welcome.fr.md) · [en](references/welcome.en.md).

## A need described in their own words
1. Find the up-to-3 tutorials that answer it with [references/routing.md](references/routing.md) (none fits → start from `premiere-app`: a tool that files the information they described, enriched afterwards).
2. Present a plan in their words: clarify the goal in one sentence and what they want to keep track of, start small with a real example, then enrich (display, website with sign-in, Telegram bot, automation). One next step at a time; build as soon as they agree.

## Conduct scripts (read and follow — never recite)
- `premier-pas` → [references/premier-pas.md](references/premier-pas.md)

`premier-pas` is the first conversation of an organization that has built nothing yet: welcome briefly, run the discovery interview, build their first tool in THIS conversation, then invite them to make the next one alone.
