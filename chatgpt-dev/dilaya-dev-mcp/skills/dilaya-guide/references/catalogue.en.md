# The app catalogue

Not sure where to start? The **Dilaya catalogue** gathers **ready-made apps**, built and shared by other users — you pick one, and it is installed for you from start to finish.

## Install an app from the catalogue

1. Ask:

> "Show me what I can **install from the Dilaya catalogue**."

2. Pick an app. Before installing, you are told **what it does** and **what will need connecting** (a Telegram bot, a calendar, sending email…), and your explicit go-ahead is awaited.
3. Everything is created — the data, the instructions, the dashboards, the automations, the site if there is one — and you are guided through connecting whatever is missing. Within minutes the app is running **for you, with your own data**.

There is also a **catalogue console** (like the management console) to browse the entries and copy the install prompt in one click:

> "Set up the Dilaya **catalogue console** for me."

## Share your own app

Built something others could use? Publish it:

> "I want to **publish my app** {name} in the Dilaya catalogue."

- **Public** = visible to every Dilaya user; **private** = your organisation only.
- Only the app's **recipe** is shared (its structure and how to use it) — **never your data**.
- Each published version is frozen; to fix something, you publish a new version.

It is a good way to equip a whole team with the same software, or to help the community get started.
